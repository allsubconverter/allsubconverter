## 📖 Introdução
**AllSubConverter** é um kit de ferramentas profissional para conversão de legendas, focado na privacidade e projetado para rodar inteiramente no seu navegador web. Ao contrário de outras ferramentas que exigem o envio de arquivos para um servidor remoto, o **AllSubConverter processa tudo localmente** usando tecnologias avançadas de JavaScript e WebAssembly.

Isso garante que suas legendas, letras de músicas e transcrições permaneçam **100% privadas e seguras** no seu dispositivo. Seja você um editor de vídeo (Premiere/Final Cut), um criador de conteúdo ou um desenvolvedor, esta ferramenta oferece conversão instantânea entre os formatos **SRT, VTT, ASS e LRC**.
