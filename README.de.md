## 📖 Einführung
**AllSubConverter** ist ein professionelles, datenschutzfreundliches Toolkit zur Konvertierung von Untertiteln, das vollständig in Ihrem Webbrowser läuft. Im Gegensatz zu anderen Tools, die Ihre Dateien auf einen Server hochladen, **verarbeitet AllSubConverter alles lokal** mithilfe fortschrittlicher JavaScript- und WebAssembly-Technologien.

Dies garantiert, dass Ihre Untertitel, Songtexte und Captions zu **100 % privat und sicher** auf Ihrem Gerät bleiben. Egal, ob Sie Video-Editor (Premiere/Final Cut), Content Creator oder Entwickler sind – dieses Tool bietet sofortige Konvertierung zwischen den Formaten **SRT, VTT, ASS und LRC**.
