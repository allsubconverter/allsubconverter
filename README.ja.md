## 📖 はじめに
**AllSubConverter** は、Webブラウザ上で完全に動作するように設計された、プロフェッショナルでプライバシー重視の字幕変換ツールキットです。ファイルを外部サーバーにアップロードする必要がある他のツールとは異なり、**AllSubConverter は高度なJavaScript技術を使用してすべてをローカル（お使いのPC内）で処理します**。

これにより、字幕ファイル、歌詞データ、キャプションの内容が **100%プライベートかつ安全** に保たれます。動画編集者（Premiere/Final Cut）、コンテンツクリエイター、または開発者の方々へ、**SRT, VTT, ASS, LRC** フォーマット間の即時変換を提供します。

## 🌟 AllSubConverterが選ばれる理由

*   **🔒 プライバシー第一:** アップロードなし、サーバーなし。データはあなたのコンピュータから出ません。
*   **⚡ 爆速処理:** クライアントサイドJSにより、変換はミリ秒単位で完了します。
*   **🌍 多言語インターフェース:** 日本語、英語、中国語、ドイツ語、スペイン語などに対応。
*   **📱 レスポンシブデザイン:** デスクトップ (Windows/Mac/Linux)、iOS、Android で完璧に動作します。
*   **🔧 面倒な準備は不要:** Pythonやffmpegのインストールは不要です。リンクを開くだけで使えます。

## 🛠️ 使い方
1.  [**AllSubConverter.com/ja**](https://www.allsubconverter.com/ja) にアクセスします。
2.  字幕ファイル（例: `.srt`, `.vtt`）を変換ボックスにドラッグ＆ドロップします。
3.  変換したいフォーマットを選択します。
4.  変換されたファイルが即座に自動ダウンロードされます。
