## 📖 소개
**AllSubConverter**는 웹 브라우저에서 완벽하게 실행되도록 설계된 개인정보 보호 중심의 전문 자막 변환 툴킷입니다. 파일을 원격 서버로 업로드해야 하는 다른 도구들과 달리, **AllSubConverter는 고급 JavaScript 기술을 사용하여 모든 작업을 로컬(사용자의 PC)에서 처리합니다**.

이는 사용자의 자막 파일, 가사 데이터, 캡션 내용이 기기에서 **100% 비공개로 안전하게** 유지됨을 보장합니다. 동영상 편집자(Premiere/Final Cut), 콘텐츠 크리에이터, 개발자 등 누구에게나 **SRT, VTT, ASS, LRC** 형식 간의 즉각적인 변환을 제공합니다.

## 🌟 AllSubConverter를 선택해야 하는 이유

*   **🔒 개인정보 보호 최우선:** 업로드 없음, 서버 없음. 데이터는 사용자의 컴퓨터를 떠나지 않습니다.
*   **⚡ 초고속 처리:** 클라이언트 사이드 JS로 구동되어 변환이 밀리초(ms) 단위로 완료됩니다.
*   **🌍 다국어 인터페이스:** 한국어, 영어, 중국어, 독일어, 스페인어, 일본어 등을 지원합니다.
*   **📱 반응형 디자인:** 데스크톱(Windows/Mac/Linux), iOS, Android에서 완벽하게 작동합니다.
*   **🔧 설치 불필요:** Python이나 ffmpeg 같은 소프트웨어를 설치할 필요가 없습니다. 링크만 열면 됩니다.

## 🛠️ 사용 방법
1.  [**AllSubConverter.com/ko**](https://www.allsubconverter.com/ko) 에 접속합니다.
2.  자막 파일(예: `.srt`, `.vtt`)을 변환 상자에 드래그 앤 드롭합니다.
3.  원하는 변환 형식을 선택합니다.
4.  변환된 파일이 즉시 자동으로 다운로드됩니다.
