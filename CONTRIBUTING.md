# Contributing to AllSubConverter

Hi there! We welcome feedback and suggestions for AllSubConverter.

Although the core conversion engine is proprietary (to ensure privacy and security logic integrity), we use this repository to host documentation and track public issues.

## How to Report Bugs
1. Go to the [Issues](https://github.com/YOUR_USERNAME/YOUR_REPO_NAME/issues) tab.
2. Click "New Issue".
3. Describe the problem, including the browser you are using and the file format.

## Feature Requests
If you want to see a new format supported (e.g., STL, SBV), please open an Issue with the tag `enhancement`.

Thank you for using AllSubConverter!
