## 📖 简介
**AllSubConverter** 是一个专业的、注重隐私的字幕转换工具箱，专为在您的 Web 浏览器中完全运行而设计。与需要将文件上传到远程服务器的其他工具不同，**AllSubConverter 使用先进的 JavaScript 技术在本地处理所有内容**。

这确保了您的字幕文件、歌词数据和字幕内容在您的设备上保持 **100% 私密和安全**。无论您是视频剪辑师（Premiere/Final Cut）、内容创作者还是开发人员，此工具都能提供 **SRT、VTT、ASS 和 LRC** 格式之间的即时转换。
