## 📖 Introduction
**AllSubConverter** is a professional, privacy-first subtitle conversion toolkit designed to run entirely in your web browser. Unlike other tools that force you to upload files to a remote server, **AllSubConverter processes everything locally** using advanced JavaScript and WebAssembly technologies.

This ensures that your subtitles, lyrics, and captions remain **100% private and secure** on your device. Whether you are a video editor using Premiere/Final Cut, a content creator for YouTube, or a developer, this tool provides instant conversion between **SRT, VTT, ASS, and LRC** formats.
